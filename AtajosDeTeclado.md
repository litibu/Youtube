# Cuadro descriptivo de atajos de teclado (Windows)

Atajos aplicables al editor/archivo mostrado (`CanalYoutubeDecideQueComer.txt`) en VS Code.

| Atajo | Acción | Descripción |
|---|---|---|
| `Ctrl+O` | Abrir archivo | Abre un archivo en el editor. |
| `Ctrl+S` | Guardar | Guarda los cambios del archivo actual. |
| `Ctrl+Shift+S` | Guardar como | Guarda el archivo con otro nombre. |
| `Ctrl+W` / `Ctrl+F4` | Cerrar editor | Cierra la pestaña del archivo actual. |
| `Ctrl+P` | Ir a archivo (Quick Open) | Abre el diálogo rápido para abrir archivos por nombre. |
| `Ctrl+F` | Buscar | Busca texto dentro del archivo abierto. |
| `Ctrl+H` | Reemplazar | Abre reemplazo en el archivo actual. |
| `Ctrl+Shift+F` | Buscar en archivos | Busca texto en todo el proyecto. |
| `Ctrl+Shift+H` | Reemplazar en archivos | Reemplaza texto en múltiples archivos del proyecto. |
| `Ctrl+G` | Ir a línea | Saltar a una línea específica. |
| `Ctrl+Shift+P` | Paleta de comandos | Ejecuta comandos y accesos rápidos de VS Code. |
| ``Ctrl+` `` | Alternar terminal | Muestra/oculta el terminal integrado. |
| `Ctrl+Shift+V` | Vista previa Markdown | Previsualiza archivos Markdown (útil si conviertes el texto). |
| `Alt+Z` | Ajuste de línea (Word Wrap) | Activa/desactiva el ajuste de línea. |
| `Ctrl+/` | Comentar línea | Comenta o descomenta la línea o selección actual. |
| `Alt+Up` / `Alt+Down` | Mover línea | Mueve la línea actual arriba/abajo. |
| `Shift+Alt+Down` | Duplicar línea | Duplica la línea o selección debajo. |
| `Ctrl+Z` | Deshacer | Deshace la última acción. |
| `Ctrl+Y` | Rehacer | Rehace la acción deshecha. |
| `Ctrl+K Ctrl+S` | Atajos de teclado | Abre la referencia de atajos de teclado en VS Code. |
| `F11` | Pantalla completa | Activa/desactiva pantalla completa. |
| `Ctrl+K Z` | Zen Mode | Entra/sale del modo Zen (sin distracciones). |
