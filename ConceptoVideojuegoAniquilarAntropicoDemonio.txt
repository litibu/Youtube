Concepto del canal Aniquilar Antropico Demoniaco en formato videojuego.

Construcción de universo narrativo permantente en formato videojuego divulgativo.

Objetivo
Defender el cuerpo humano de ataques parasitarios antropicos demoniacos.

Estructura del videojuego
Adaptarla al "viaje del heroe", monomito de Joseph Campbell.

| Elemento real | Traducción al videojuego |
|---|---|
| Cuerpo humano | **Mapa / mundo del juego** |
| Órganos | Niveles |
| Parásito | Boss/enemigo |
| Sistema inmune | Ejército aliado |
| Macrófagos | Unidades defensivas |
| Anticuerpos | Armas especiales |
| Vector | Vehículo de infiltración |
| Huevo/quiste | Forma de resistencia |
| Infección | Invasión |
| Síntomas | Damage effects |
| Diagnóstico | Scanner |
| Tratamiento | Power-up médico |
| Higiene | Escudo preventivo |
| Agua segura | Defense item |
| Cocción de alimentos | Weapon/defense |
| Mosquitero | Barrier |
| Prevención | **Forma de ganar la partida** |
