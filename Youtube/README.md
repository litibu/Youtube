# Youtube
## Canales para youtube
Creación  de guiones para vídeos para diferentes canales de youtube. 

### **Chisme para llevar** @ChismeParaLlevar
Objetivo mostrar una preparación practica y sabrosa de un alimento funcional o remedio, en paralelo con la 
narración de dialogo (faceless) relacionada al alimento que se prepara. 

### **Decide que comer** @DecideQueComer
Su objetivo es ayudar a decidir que comer entre alimentos, platillos y/o bebidas. Narración faceless en dialogo con interlocutora femenina.

### **Juicio Alimento Cotidiano** 
Su objetivo es dar al consumidor información real de los alimentos industrializados que compran. 

### **Asesino Monstruos**
Exponer al espectador como sobrevivir ante el ataque de parasitos monstruosos, explicada en formato de vídeo juegos.
